# Mehmet Atalay – kişisel web sitesi

Bu klasör GitHub Pages için hazırlanmış statik bir web sitesidir.

## Dosyalar
- `index.html` — site içeriği
- `style.css` — tasarım ve mobil uyumluluk
- `script.js` — mobil menü

## GitHub Pages'e yayınlama
1. GitHub hesabı açın/giriş yapın.
2. Yeni bir repository oluşturun. Örn: `mehmetatalay.com.tr`
3. Bu üç dosyayı repository'nin ana klasörüne yükleyin.
4. Settings → Pages → Deploy from a branch → `main` → `/root` seçin.
5. GitHub Pages adresiniz oluşunca Custom domain alanına `mehmetatalay.com.tr` yazın.
6. SH Online DNS yönetiminde GitHub'ın verdiği DNS kayıtlarını tanımlayın.
7. HTTPS seçeneğini açın.

Alan adı DNS ayarları için GitHub'ın güncel talimatlarını takip edin.
